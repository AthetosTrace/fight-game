# Ascendant Impact Operating Rules

- Treat the `fight-game` repository as the approved design and documentation source of truth.
- Do not silently redefine approved combat mechanics.
- Keep implementation Blueprint-first.
- Do not import anything into Unreal without explicit human approval.
- Do not directly edit binary Unreal assets.
- Do not install plugins or frameworks without explicit human approval.
- Do not add scope outside the single-duel prototype.
- Keep only Attack A enabled until its complete loop passes.
- Keep Attacks B-D planned and disabled.
- Do not add runtime LLM or generative-NPC behavior.
- Never commit generated Unreal folders, including `Binaries/`, `DerivedDataCache/`, `Intermediate/`, `Saved/`, `.vs/`, or plugin-local `Binaries/` and `Intermediate/` folders.
- Report planned changes before modifying project architecture.
