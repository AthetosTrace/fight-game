# Ascendant Impact

A one-versus-one cyber-fantasy martial-arts duel built in **Unreal Engine 5.8** for PC.
The player fights **Crimson Vanguard** in an octagonal industrial arena — a 2.5D combat
axis inside a 3D space, with a fixed duel camera, jump-over side switching, and an
authored, deterministic opponent.

Capstone project for **Multi-Agent AI for Game Development**.
Built by **Adrian Delgado**, with **Omar**.

---

## The AI pipeline that built the arena

The arena in the shipping build was not hand-placed. It was **generated by a
generate → evaluate → refine pipeline** in [`game/Tools/ArenaPipeline/`](game/Tools/ArenaPipeline/),
and its output lands directly in the engine as placed level actors with no manual
reformatting step.

```
contracts/arena_rules.json   the authored rules the arena must satisfy
        |
   generator.py              proposes an arena plan (JSON)
        |
   evaluator.py              scores it against the rules
        |
   refiner.py                fixes what failed, loops back
        |
 validate_arena_plan.py      deterministic gate — fails closed
        |
  materializer.py            plan -> Unreal actors, via MCP, inside the editor
        |
  Lvl_DuelGraybox            30 ArenaOct_* actors, in the cooked build
```

**The connection is verifiable, not asserted.** The generators read the *live* level for
spawn points and floor height rather than assuming world origin; they chose the fighter
clamp centre `(0,0,0)` and grew the octagon's `centre_to_face` to 1590 cm to satisfy an
authored camera-containment rule. The resulting 30 actors were diffed both ways against
the reference arena with nothing on either side, and the level packaged clean afterwards.

Evidence, with screenshots and the numbers the build reported, is committed at
[`game/reports/arena/`](game/reports/arena/).

Run the pipeline's tests:

```
py -3 -m unittest discover game/Tools/ArenaPipeline/tests
```

## The game

| | |
|---|---|
| **Engine** | Unreal Engine 5.8, Blueprint-only — no C++, no `Source/` |
| **Project** | [`game/AscendantImpact.uproject`](game/) |
| **Shipping level** | `/Game/AscendantImpact/Maps/Lvl_DuelGraybox` |
| **Platform** | Windows, packaged Shipping build |

**Working:** player movement, jump-over with dynamic side switching, punch, health,
hit-react, camera shake and ragdoll death · a Vanguard with range-band AI movement,
directional locomotion and a telegraphed strike that is interruptible before impact and
honestly dodgeable · a 2.5D duel camera with mutual facing and arena bounds · a duel HUD
with both health bars · a knockout coordinator · the full octagon arena.

**In progress:** win/lose/restart, two more Vanguard attacks, balance, and a visual pass.
The full remaining scope is [`FINISH-PLAN.md`](FINISH-PLAN.md).

## Working on this

The editor and its MCP server must be running **before** a session opens.
[`START-HERE.md`](START-HERE.md) has the process; the short version is:

```powershell
# 1. open game/AscendantImpact.uproject
# 2. in the editor console:  ModelContextProtocol.StartServer
pwsh -File start-session.ps1
claude
```
