# Ascendant Impact

Ascendant Impact is an Unreal Engine 5.8 PC production project built with a Blueprint-first approach.

## Repository role

This repository contains the Unreal implementation and binary assets for the approved single-duel prototype. The approved design and planning source is the [fight-game repository](https://github.com/anthonytra785/fight-game).

The prototype delivers one complete duel in which the player uses Echo or Nova against Crimson Vanguard. Echo and Nova share one core combat framework. Crimson Vanguard uses authored, deterministic AI.

## Combat scope

- Attack A is initially enabled and must complete its full loop first.
- Attacks B-D remain planned and disabled.
- Runtime generative AI is not used.

The project does not include PvP, multiplayer, additional fighters, additional arenas, progression, or campaign expansion.

## Reference project

`CombatRef_UE58` is a disposable reference project and is not part of this repository.
