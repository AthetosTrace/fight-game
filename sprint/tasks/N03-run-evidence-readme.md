## Goal

A recorded session proving consistency across five or more turns, and the ReadMe the
rubric asks for.

## Preconditions

- `N02` complete.

## Steps

1. Play a real session of at least five turns. Do not script it to look good — the
   surprising moment the ReadMe needs comes from a genuine run.
2. Deliberately test consistency: establish a fact early, do several unrelated turns, then
   put the agent in a position where forgetting it would show. Record what happened.
3. Save the transcript and the per-turn ledger snapshots under
   `assignment-08/evidence/`, following the shape Assignments 06 and 07 used
   (`evidence/runs/<name>/run.json` + `run.md`).
4. Write the ReadMe: the world, what the ledger tracks, and **one specific moment where the
   agent surprised you.** That last one is a real observation from a real run, not a
   flourish.
5. Note the run cost from the `N01` helper — `G11` will reuse it.

## Done when

- [ ] A 5+ turn transcript is committed with per-turn ledger snapshots.
- [ ] The consistency test is documented: what fact, how many turns apart, what happened.
- [ ] The ReadMe covers world, ledger, and one genuine surprise.
- [ ] Run cost recorded.
- [ ] Committed on `assignment-08/narrative-engine`.
